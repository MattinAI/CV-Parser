# Langflow Flows Directory

## Overview

This folder contains different workflow definitions developed using Langflow. 

## Structure

Each workflow is stored inside a separated directory, containing the necessary configurations, nodes, and connections to function within the Langflow environment.

## Usage

- To modify or create a new flow, open Langflow and import/export the desired workflow.

- Alternatively, workflows can be uploaded directly to the backend for execution.

- Each flow includes a .py file that contains the necessary execution logic to interact with the workflow programmatically.

## Contribution

When adding a new flow:

1. Name the file or folder descriptively.

2. Include a brief explanation of its purpose.

This directory serves as the central repository for our Langflow-based workflow development.
